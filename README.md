# heweeps.com (legacy site)

Static HTML site for **heweeps.com** — the current live design, not the Mastropolo Arts Next.js rebuild.

## Branches

| Branch | Purpose |
|--------|---------|
| `main` | Matches production heweeps.com (deploy only when ready to go live) |
| `dev` | Client preview: Michael’s requested edits |

## Preview (dev)

After push to `dev`, open the Vercel **Preview** URL for that branch (see Vercel dashboard or deployment comment).

Typical paths:

- Home: `/index.html` or `/`
- 7th Hole: `/7th_hole_pebble.htm`
- Store: `/store/index.htm`

## Local

Open `index.html` in a browser, or use any static server from this directory.

## Deploy

Connected to Vercel. **Production** = `main` → heweeps.com when DNS is pointed at this project.
